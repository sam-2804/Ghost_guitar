# Ghost_guitar
Ghost guitar is an application that lets user's play guitar virtually by using their devices in-built camera


## Languages

- **Python 3.14.3** - Base programming Language

## Libraries used

- **opencv-python** - Used to stream video from your camera
- **mediapipe** - library by google used to run the hand tracking model 
- **pygame-ce** - used to play the chords (acts as a mixer)

### optional - If you like to use create_chords.py

- **mido** - for generating MIDI files.
- **fluidsynth-v2.6.1** - Synthesizer for generating .wav files for chords. [Link text](https://github.com/FluidSynth/fluidsynth/releases/tag/v2.6.1)
